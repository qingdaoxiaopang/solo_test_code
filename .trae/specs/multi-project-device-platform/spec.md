# 多项目设备安装运维平台规格说明书

## 背景与目标

企业设备安装运维管理面临多项目并行、跨部门协作、现场数据采集等挑战。本平台旨在构建一个统一的设备安装运维管理系统，支持多项目独立管理、设备全生命周期追踪、现场安装运维流程数字化、跨设备类型适配，同时支持PC端和移动端多终端访问。

## 技术架构

### 后端技术栈

- **运行环境**: Java 17
- **框架**: Spring Boot 3.5.x
- **数据库**: SQLite（轻量级、零配置、适合运维场景）
- **ORM**: MyBatis-Plus（提供强大的CRUD和分页功能）
- **API风格**: RESTful API
- **认证**: JWT Token认证
- **API文档**: Swagger/OpenAPI 3.0

### 前端技术栈

- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **UI组件库**: Element Plus（PC端）、Vant（移动端）
- **状态管理**: Pinia
- **路由**: Vue Router 4
- **HTTP客户端**: Axios
- **响应式**: Tailwind CSS

## 核心功能模块

### 1. 项目管理模块

#### 1.1 项目基本信息管理

- 项目的增删改查（CRUD）操作
- 项目编码（唯一标识）、项目名称、项目类型、项目状态
- 项目负责人、联系方式、项目地址
- 项目开始/结束日期
- 项目备注信息

#### 1.2 项目组织架构

- 项目下可创建多个站点/区域
- 站点层级关系管理
- 站点关联设备统计

#### 1.3 项目数据隔离

- 每个项目数据完全隔离
- 项目切换器快速切换项目上下文
- 支持按项目进行数据筛选和统计

### 2. 设备管理模块

#### 2.1 设备台账管理

- 设备基础信息：设备编号、名称、型号、规格、生产厂商
- 设备分类：按照设备类型分类（电气设备、机械设备、仪表设备等）
- 设备状态：库存、在安装、已安装、运行中、维修中、报废
- 设备位置：所属项目、所属站点、安装位置
- 设备参数：自定义设备参数和参数值
- 设备照片：支持设备照片上传和查看

#### 2.2 设备二维码管理

- 每个设备生成唯一二维码
- 二维码包含设备ID和项目ID
- 支持二维码批量生成和打印
- 扫码快速查看设备信息

#### 2.3 设备全生命周期追踪

- 设备入库记录
- 设备领用/分配记录
- 设备安装记录
- 设备运行记录
- 设备维修记录
- 设备报废记录
- 完整生命周期时间轴展示

### 3. 安装管理模块

#### 3.1 安装任务管理

- 安装任务创建、分配、跟踪
- 安装任务状态：待分配、执行中、待验收、已完成
- 安装计划时间、实际时间记录
- 安装人员安排
- 安装进度跟踪

#### 3.2 安装现场管理

- 安装位置确认
- 安装条件检查清单
- 安装过程记录（文字、照片）
- 安装材料使用记录
- 安装问题记录与反馈
- 安装验收签字（电子签名）

#### 3.3 安装文档管理

- 安装手册关联
- 安装验收标准
- 安装完成报告生成
- 安装档案归档

### 4. 运维管理模块

#### 4.1 运维工单管理

- 工单类型：巡检、维护、故障报修、紧急维修
- 工单创建、派单、接单、完成、评价流程
- 工单优先级：紧急、高、中、低
- 工单状态：待派单、待接单、处理中、待验收、已完成
- 工单详情：问题描述、位置、照片附件
- 工单处理记录（时间线）

#### 4.2 巡检管理

- 巡检计划制定（周期、路线）
- 巡检任务下发
- 巡检点二维码扫描签到
- 巡检项检查（设备状态、参数记录）
- 巡检异常记录
- 巡检报告生成

#### 4.3 设备维修管理

- 故障报修登记
- 维修人员派工
- 维修过程记录
- 维修材料使用
- 维修完成验收
- 维修费用统计

#### 4.4 备件管理

- 备件库存管理
- 备件入库、出库记录
- 备件库存预警
- 备件使用统计

### 5. 报表统计模块

#### 5.1 项目统计

- 项目设备数量统计
- 项目完成进度统计
- 项目人员工时统计

#### 5.2 设备统计

- 设备状态分布统计
- 设备类型分布统计
- 设备故障率统计

#### 5.3 运维统计

- 工单数量统计（按时段、类型、状态）
- 工单响应时间统计
- 工单完成率统计
- 运维人员工作量统计

#### 5.4 数据可视化

- 仪表盘首页展示关键指标
- 图表可视化（柱状图、饼图、折线图）
- 统计报表导出（Excel）

### 6. 系统管理模块

#### 6.1 用户权限管理

- 用户管理：用户增删改查、密码管理
- 角色管理：预定义角色（超级管理员、项目管理员、运维工程师、现场人员）
- 权限管理：功能权限和数据权限
- 部门管理：组织架构管理

#### 6.2 系统设置

- 字典数据管理（设备类型、故障类型等）
- 流程配置（运维流程自定义）
- 通知设置（站内消息）
- 系统参数配置

#### 6.3 操作日志

- 用户操作日志记录
- 系统异常日志
- 日志查询和导出

## API接口规范

### 认证接口

- POST `/api/auth/login` - 用户登录
- POST `/api/auth/logout` - 用户登出
- GET `/api/auth/current-user` - 获取当前用户信息

### 项目管理接口

- GET/POST `/api/projects` - 项目列表/创建
- GET/PUT/DELETE `/api/projects/{id}` - 项目详情/更新/删除
- GET `/api/projects/{id}/sites` - 项目站点列表
- GET `/api/projects/{id}/stats` - 项目统计数据

### 设备管理接口

- GET/POST `/api/devices` - 设备列表/创建设备
- GET/PUT/DELETE `/api/devices/{id}` - 设备详情/更新/删除
- GET `/api/devices/{id}/lifecycle` - 设备生命周期
- GET `/api/devices/qrcode/{id}` - 获取设备二维码
- POST `/api/devices/batch-qrcode` - 批量生成二维码

### 运维接口

- GET/POST `/api/work-orders` - 工单列表/创建工单
- GET/PUT `/api/work-orders/{id}` - 工单详情/更新工单
- POST `/api/work-orders/{id}/handle` - 处理工单
- POST `/api/work-orders/{id}/complete` - 完成工单

### 巡检接口

- GET/POST `/api/inspections/plans` - 巡检计划
- GET/POST `/api/inspections/tasks` - 巡检任务
- POST `/api/inspections/checkin` - 巡检查到

## 安全要求

- JWT Token认证，Token有效期24小时
- 密码加密存储（BCrypt）
- SQL注入防护
- XSS攻击防护
- CORS跨域配置
- 接口访问频率限制
- 敏感操作日志记录

## 性能要求

- 接口响应时间 < 200ms（不含文件上传）
- 支持1000+设备数据管理
- 支持100+并发用户
- 支持移动端离线缓存（本地存储）
