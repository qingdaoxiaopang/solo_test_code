# 多项目设备安装运维平台规格说明书

## 一、技术要求

### 1. 技术架构概述

本平台采用前后端分离架构，后端使用Java 17 + Spring Boot 3.5.x，前端使用Vue 3 + Vite，支持PC端和移动端多终端访问。

### 2. 后端技术栈

| 技术项 | 技术选型 | 说明 |
|--------|----------|------|
| 运行环境 | Java 17 | LTS版本 |
| 框架 | Spring Boot 3.5.x | 最新稳定版本 |
| 数据库 | PostgreSQL 13.x+ | 企业级关系型数据库 |
| ORM | MyBatis-Plus | 强大的CRUD和分页功能 |
| 认证框架 | Sa-Token | 轻量级权限认证，支持Token认证、会话管理、路由拦截 |
| API文档 | Swagger/OpenAPI 3.0 | 接口文档自动生成 |
| API风格 | RESTful API | 统一接口规范 |

### 3. 前端技术栈

| 技术项 | 技术选型 | 说明 |
|--------|----------|------|
| 框架 | Vue 3 | Composition API |
| 构建工具 | Vite | 快速开发体验 |
| PC端UI | Element Plus | 企业级组件库 |
| 移动端UI | Vant | 轻量级移动端组件库 |
| 状态管理 | Pinia | Vue 3专用状态管理 |
| 路由 | Vue Router 4 | SPA路由管理 |
| HTTP客户端 | Axios | HTTP请求封装 |
| 响应式 | Tailwind CSS | 原子化CSS框架 |

### 6. 响应式设计要求

#### 6.1 PC端（≥1024px）

- 左侧导航菜单 + 顶部工具栏
- 表格列表展示为主
- 详情页侧滑抽屉展示
- 支持批量操作
- 数据图表可视化

#### 6.2 移动端（<768px）

- 底部Tab导航
- 卡片列表展示为主
- 全屏详情页
- 简化表单输入
- 离线数据缓存（可选）

#### 6.3 平板（768px - 1024px）

- 自适应布局
- 导航可折叠
- 表格可横向滚动

### 7. 安全要求

- Sa-Token认证框架，Token会话管理
- 密码加密存储（BCrypt）
- SQL注入防护
- XSS攻击防护
- CORS跨域配置
- 接口访问频率限制
- 敏感操作日志记录

### 8. 性能要求

- 接口响应时间 < 200ms（不含文件上传）
- 支持1000+设备数据管理
- 支持100+并发用户
- 支持移动端离线缓存（本地存储）
