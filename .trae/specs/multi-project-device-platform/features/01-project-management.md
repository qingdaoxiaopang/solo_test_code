# 项目管理模块

## 1. 模块概述

项目管理模块是整个平台的基础模块，用于管理多个项目，实现项目级别的数据隔离和快速切换。每个项目包含完整的设备、安装、运维等业务数据。

## 2. 用户故事

作为项目经理，我需要创建新项目并设置项目基础信息，包括项目编码、名称、负责人、区域信息和定位坐标。我可以在地图上标记项目位置，设置项目阶段和时间范围。项目创建后，我能管理项目成员，为不同成员分配管理员、普通成员或查看者角色。进入项目详情页，我可以查看项目统计数据（设备数量、工单数量等）和设备列表，通过地图直观查看项目位置。当项目进度变化时，我可以更新项目状态并记录变更原因，系统会自动通知相关成员。

## 7. 业务流程

### 7.1 项目创建流程

```
1. 用户点击"新增项目"按钮
2. 填写项目基本信息（编码、名称、区域信息等）
3. 选择项目负责人
4. 设置项目时间范围
5. 选择项目阶段
6. 设置项目定位坐标（可选地图选点）
7. 提交表单
8. 系统验证数据唯一性
9. 保存项目信息
10. 返回成功提示
```

### 7.2 项目成员管理流程

```
1. 进入项目详情页
2. 点击"成员管理"tab
3. 查看现有成员列表
4. 可添加新成员（选择用户，设置角色）
5. 可修改成员角色
6. 可移除成员
7. 成员变更自动记录到操作日志
```

### 7.3 项目状态变更流程

```
1. 项目管理员进入项目设置
2. 点击"变更状态"按钮
3. 选择目标状态
4. 填写变更原因（可选）
5. 确认变更
6. 系统记录状态变更历史
7. 状态变更通知相关成员
```
