# 项目管理模块

## 1. 模块概述

项目管理模块是整个平台的基础模块，用于管理多个项目及其下属站点，实现项目级别的数据隔离和快速切换。

## 2. 功能清单

### 2.1 项目管理

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 项目列表 | 展示所有项目，支持分页、搜索、筛选 | P0 |
| 项目新增 | 创建新项目，填写项目基本信息 | P0 |
| 项目编辑 | 修改项目信息 | P0 |
| 项目删除 | 删除项目（需确认） | P1 |
| 项目详情 | 查看项目完整信息 | P0 |
| 项目统计 | 展示项目的设备数量、人员工时等统计 | P1 |

### 2.2 站点管理

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 站点列表 | 展示项目下所有站点 | P0 |
| 站点新增 | 在项目下创建新站点 | P0 |
| 站点编辑 | 修改站点信息 | P0 |
| 站点删除 | 删除站点（需确认） | P1 |
| 站点设备统计 | 展示站点的设备数量 | P1 |

### 2.3 项目切换器

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 项目下拉选择 | 快速切换当前项目上下文 | P0 |
| 最近访问项目 | 显示最近访问的项目 | P2 |
| 移动端适配 | 移动端项目切换交互优化 | P1 |

## 3. 数据模型

### 3.1 项目表 (prj_project)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| code | VARCHAR(50) | 项目编码（唯一） |
| name | VARCHAR(100) | 项目名称 |
| type | VARCHAR(50) | 项目类型 |
| status | VARCHAR(20) | 项目状态 |
| manager_id | BIGINT | 负责人ID |
| contact | VARCHAR(50) | 联系方式 |
| address | VARCHAR(200) | 项目地址 |
| start_date | DATE | 开始日期 |
| end_date | DATE | 结束日期 |
| remark | TEXT | 备注 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

### 3.2 站点表 (prj_site)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| project_id | BIGINT | 所属项目ID |
| parent_id | BIGINT | 父站点ID（支持层级） |
| code | VARCHAR(50) | 站点编码 |
| name | VARCHAR(100) | 站点名称 |
| type | VARCHAR(50) | 站点类型 |
| address | VARCHAR(200) | 站点地址 |
| remark | TEXT | 备注 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

## 4. API接口

### 4.1 项目接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/projects | 项目列表（分页+筛选） |
| POST | /api/projects | 创建项目 |
| GET | /api/projects/{id} | 项目详情 |
| PUT | /api/projects/{id} | 更新项目 |
| DELETE | /api/projects/{id} | 删除项目 |
| GET | /api/projects/{id}/stats | 项目统计数据 |

### 4.2 站点接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/projects/{projectId}/sites | 站点列表 |
| POST | /api/projects/{projectId}/sites | 创建站点 |
| GET | /api/sites/{id} | 站点详情 |
| PUT | /api/sites/{id} | 更新站点 |
| DELETE | /api/sites/{id} | 删除站点 |
| GET | /api/sites/{id}/stats | 站点统计数据 |

### 4.3 项目切换器接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/projects/accessible | 获取用户可访问项目列表 |
| PUT | /api/projects/current | 设置当前项目上下文 |

## 5. 业务流程

### 5.1 项目创建流程

```
1. 用户点击"新增项目"按钮
2. 填写项目基本信息（编码、名称、类型等）
3. 选择项目负责人
4. 设置项目时间范围
5. 提交表单
6. 系统验证数据唯一性
7. 保存项目信息
8. 返回成功提示
```

### 5.2 站点管理流程

```
1. 进入项目详情页
2. 查看站点列表
3. 可新增子站点（支持多级层级）
4. 每个站点可关联设备
5. 统计各站点设备数量
```

## 6. 前端页面

| 页面 | 路由 | 说明 |
|------|------|------|
| 项目列表 | /projects | 项目表格展示 |
| 项目详情 | /projects/:id | 项目信息展示 |
| 项目表单 | /projects/form | 新增/编辑项目 |
| 站点管理 | /projects/:id/sites | 站点列表和管理 |
